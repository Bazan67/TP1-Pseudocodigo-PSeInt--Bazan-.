## Listado de Ejercicios

| Archivo | Funcionalidad / Descripción |
| :--- | :--- |
| Ejercicio 01.psc | Cotización de hardware con cálculo de subtotal, descuento por cantidad e impuestos encadenados como IVA e IIBB. |
| Ejercicio 02.psc | Módulo logístico de flotas que calcula consumo de combustible, costos, paradas mínimas y duración exacta del viaje. |
| Ejercicio 03.psc | Simulador financiero de compra de divisas con cálculo de comisiones bancarias, impuesto PAIS, ganancias y tipo de cambio tarjeta. |
| Ejercicio 04.psc | Boletín académico ponderado que determina la condición del alumno (Promocionado, Regular, Libre) según notas y asistencia. |
| Ejercicio 05.psc | Cálculo cronológico de antigüedad y días totales vividos a partir de la fecha de nacimiento y la fecha actual. |
| Ejercicio 06.psc | Facturación escalonada de servicios ISP con cálculo de excedente de GB de internet y recargo por pago fuera de término. |
| Ejercicio 07.psc | Optimización de empaque industrial que calcula la producción neta y su distribución exacta en palets, cajas y unidades sueltas. |
| Ejercicio 08.psc | Análisis geométrico analítico de un triángulo rectángulo que calcula hipotenusa, perímetro, área y ángulos internos agudos. |
| Ejercicio 09.psc | Sistema POS de punto de venta que aplica descuentos o recargos según 5 modalidades de pago y calcula valor de cuotas. |
| Ejercicio 10.psc | Liquidación avanzada de haberes que calcula horas extras (50% y 100%), sueldo bruto, deducciones de ley y sueldo neto. |

## Instrucciones de Ejecución
1. Descargar e instalar PSeInt.
2. Abrir el programa.
3. Ir a Archivo > Abrir y seleccionar el archivo .psc deseado de este repositorio.
4. Hacer clic en el botón verde de Ejecutar (o presionar la tecla F9).
